## Plantilla Base

Cada ADR debe estructurarse con:

1. **Contexto y Problema:** Qué necesidad o restricción técnica motivó la decisión.
2. **Opciones Consideradas:** Alternativas analizadas con pros y contras.
3. **Decisión:** La solución adoptada y su justificación.
4. **Consecuencias:** Impacto técnico positivo, riesgos o compromisos asumidos.
